# .github

Org-wide defaults for [rblx-vibecode](https://github.com/rblx-vibecode).

- `.github/ISSUE_TEMPLATE/`: issue forms (game-idea, update, bug, finding, feature) used by every org repo that doesn't define its own. Each adds the issue to the org Project.

Game repos made from `game-template` must not add their own `ISSUE_TEMPLATE/` folder, or these defaults stop applying there.

This repo must stay public: GitHub only reads default community health files from a public `.github` repo. Never put anything private here.

See [agent-fleet/docs/PLAN.md](https://github.com/rblx-vibecode/agent-fleet/blob/main/docs/PLAN.md) for how issues flow through the board.
